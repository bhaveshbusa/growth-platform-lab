# Growth Platform Lab

A small, deliberately breakable system for learning **observability** (traces, metrics, logs), **customer data platform (CDP)** mechanics, and **product analytics** — built one reviewable phase at a time.

Phase 1 lands the scope, service boundaries, and tracking plan. See the pull requests for each phase.

This repository is **not a production analytics platform** and must not be used to collect real user data.
